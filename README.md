# Lingua

On-device voice translator and English dictionary for Android. Speak or type a sentence and get a
spoken, streamed translation between English and Chinese — no network, no cloud, nothing leaves
your phone.

Built on Google LiteRT-LM + MediaPipe, targeting the Xiaomi 14 Pro (Snapdragon 8 Gen 3).

## Features

- **Translate** — EN ⇄ 中文 with auto language detection. Hold the mic and speak (Qwen3-ASR
  transcribes both languages), or type. The translation streams from Gemma 4 E2B and is spoken
  aloud in the target language (Kokoro `af_heart` for English, `zf_xiaoxiao` for Chinese).
  One-tap copy, re-speak, and an "Explain this sentence" grammar/vocab breakdown.
- **Dictionary** — instant offline lookups of 60,000 words (ECDICT subset, MIT license): IPA
  phonetics, part of speech, exam tags (CET4/CET6/IELTS/…), inflected forms, Chinese senses,
  English definition. Misses show suggestions; Chinese queries search by meaning. One-tap
  pronunciation and an AI explanation of the word.
- **Wordbook** — star words to collect them; reopen, pronounce, or remove from the list.
- **Practice** — chat with Lily, an English-tutor persona. She replies in simple English,
  gently corrects mistakes, and speaks while still generating. New-chat resets the conversation.

## Models

Model files are **not** bundled in the APK. After installing, push them to the device:

```bash
adb shell mkdir -p /sdcard/Android/data/com.typedefai.lingua/files/models
adb push models/gemma-4-E2B-it.litertlm \
           models/qwen3_asr_0.6b_5s_i8.litertlm \
           models/kokoro_int8_gpu_fp16.litertlm \
           /sdcard/Android/data/com.typedefai.lingua/files/models/
```

Keep the original filenames — MediaPipe detects the model type from them. Optional alternatives
(`moonshine_tiny_5s_i8.litertlm`, `phonon_int8.litertlm`) are selectable in Settings → Audio when
present.

| Stage | Default bundle | Size |
|---|---|---|
| LLM (translation + tutor) | `gemma-4-E2B-it.litertlm` | 2.4 GB |
| ASR (EN + ZH speech) | `qwen3_asr_0.6b_5s_i8.litertlm` | 915 MB |
| TTS (EN + ZH voices) | `kokoro_int8_gpu_fp16.litertlm` | 289 MB |

## Build

JDK 21+, Android SDK platform 37:

```bash
./gradlew :app:assembleDebug
```

Requires Android 12+ (minSdk 31). The debug APK is ~300 MB (native LiteRT-LM/MediaPipe libs plus
the 12.5 MB dictionary database).

## Dictionary data

`app/src/main/assets/databases/ecdict.db` is a frequency-trimmed SQLite subset of
[ECDICT](https://github.com/skywind3000/ECDICT) (MIT License), generated by
`scripts/build_dict.py`:

```bash
python3 scripts/build_dict.py --top 60000
```
